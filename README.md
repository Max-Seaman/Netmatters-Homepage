# Netmatters Homepage Recreation

## Overview
This project is a recreation of the homepage of web development firm Netmatters.

This project uses HTML, CSS (using SASS), JavaScript, PHP, and SQL

## Running this project locally
The steps for running thsi project locally are:
1. Set up a local MYSQL database and import the `netmatters-homepage.sql` file in the project.
2. Place the databse connection details into a .env file following the example provided
3. Host both the PHP code and the MYSQL database.
